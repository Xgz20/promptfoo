# AStudio视觉模型选型评测报告

报告日期为2026年11月10日，采用同日11时48分52秒导出的补跑后结果。评测覆盖自建评测集 `astudio-v1` 的100道单图理解题，比较8个模型，目的是为AStudio选择视觉理解模型。

## 1. 结论

**建议AStudio将Qwen3.8 Flash作为本轮单图理解的主选模型。** 它的总平均分为95.80分，单题平均成本估算为0.005032元，按本轮用量分布折合每千题约5.03元。

- GLM-5.3-Flash、MiniMax M3和Qwen3.8 Flash的总分均达到95分。Qwen比最高分GLM低1.34分，成本低49.85%。与MiniMax相比，它少0.93分，成本低87.44%。在这三款高分候选中，Qwen成本最低。95分在这里用于划分本轮高分候选组。
- Qwen各场景得分为92.22～98.67分，在海报、插画与漫画及文档与票据两类中取得本轮最高分。
- 相比豆包Seed 2.0 Mini，Qwen总分高5.04分，精确定位多答对32个检查点，完整正确的标准批注多12条。对应的额外费用约为每千题0.95元。

GLM-5.3-Flash适合作为效果优先的候选。它以97.14分取得最高总分，在本轮15道统计图表题上得分为100分，批注目标识别答对85/85点。对应的单题成本约为Qwen的1.99倍，平均请求耗时为54.27秒，Qwen为21.71秒。

豆包提供低成本对照。按“总平均分÷单题平均成本”计算，其单位成本得分约为22,222分/元，位列第一。Qwen的主选建议侧重高分组成本与AStudio批注、定位任务的收益。

## 2. 整体对比

GLM、MiniMax和Qwen三款模型的总分位于95.80～97.14分之间，千题成本估算分别为10.03、40.07、5.03元。GLM相对Qwen多1.34分，按本轮用量分布计算，每千题多5.00元。

Qwen3-VL-Plus的千题成本最低，为3.99元，总分为85.57分。Qwen3.8 Flash每千题多花1.04元，增加10.23分。豆包每千题费用为4.08元，总分90.76分，比Qwen3-VL-Plus多花约0.09元，增加5.19分。

耗时和费用呈现不同排序。Kimi的平均耗时最短，为6.15秒，总分88.80分，千题成本估算为17.25元。MiMo原9个失败题补跑后，总分由55.98升至63.86分，千题成本估算为38.00元。其91份原结果与9份补跑结果共同构成当前100题汇总。

### 统计口径与结果范围

- 每题输入为一张原图和完整Prompt，输出为文字或结构化答案。图片、题干和评分标注按原批次冻结快照及哈希核验。
- 单题基础分为正确检查点数除以适用检查点数，再乘100。有批注题按既定规则对额外修改每条扣10分，最低0分。总平均分为100题最终分数之和除以100。场景分以该场景题数为分母。
- 语义检查点由GPT API裁判 `gpt-6.1-sol`、`reasoning_effort=high` 判为0或1，几何位置由程序按题目规则判定。本轮800份当前结果均已评分。
- 原批次候选模型间并发8路，每模型内部1路，定点补跑时保持单模型内部1路。所有候选请求显式传入 `max_tokens=32768`。豆包与Qwen3.8 Flash显式设置温度0，其余采样参数及思考设置沿用各渠道默认值。这里记录客户端请求参数，渠道的有效生成范围按各自接口规则生效。结论对应上述调用配置。
- 耗时从客户端准备发出请求开始，到完整响应解析或请求报错结束。总token取接口usage，包含接口计入的推理token。
- 每题成本分别计算普通输入、缓存读、缓存写和输出，再按题平均。价格根据实际渠道、输入档位与请求时段匹配，使用2026年11月9日的公开价快照。千题费用沿用本轮题目和缓存分布进行换算。
- 费用、token和耗时均对应每题当前入选请求。历史失败尝试、独立诊断和裁判开销单独留存，完整实际支出需结合平台账单核对。
- 首轮异常记录为GLM 3次、MiMo 9次，其余模型0次。GLM记录为约301秒的传输失败，客户端响应头等待上限随后由300秒修正为600秒。MiMo记录为输出达到32768 token、结束原因为length且候选记录中的最终回答为空。同参数诊断与补跑能取得正常回答，原9次的完整响应留存缺口限制了逐条内部原因归因。
- 本版采用GLM三题和MiMo九题重新评分后的结果。MiMo两题采用首次同参数完整诊断响应，其余七题重新调用。首轮异常列保留原批次记录数，当前各模型均有100份已评分结果。

## 4. 能力对比

精确坐标定位和批注完整正确率是Qwen与更低价候选之间差距较大的两项。Qwen在145个定位检查点中答对128个，豆包答对96个；在85条标准批注中，Qwen有72条完整正确，豆包为60条。豆包文字识别答对128/130点，Qwen答对127/130点，二者在该项相差1个检查点。

MiniMax在定位和批注完整正确率上均为本轮最高，分别为135/145（93.10%）和79/85（92.94%）。相比Qwen，分别多7个正确定位点和7条完整正确批注，千题成本增加约35.04元。GLM对应结果为132/145和77/85，千题成本为10.03元，提供了另一档质量与费用取舍。

批注完整正确率同时要求目标绑定、修改意图与保留约束、几何位置全部通过。Kimi的批注意图理解为305/305，精确定位为81/145，完整正确批注为42/85。语义、目标和位置需要分别查看，完整正确率用于衡量一条批注要求整体满足的情况。

MiMo在补齐原9个失败题的候选回答并重新评分后，精确定位为36/145（24.83%），完整正确批注为28/85（32.94%）。这两项给出了其在本组任务上的具体差距。
