# 视觉评测的能力与场景得分统计

本文定义 `astudio-v1` 当前100题的评分与统计口径，对应评分版本 **`point-mean-v1`**。

后续模型选型的五 Sheet Excel 报告采用已确认的新汇总口径，整体和场景按题平均，能力按正确检查点数/适用检查点数计算。入口与公式见 [视觉模型评测与报告](vision-report.md)。下文保留历史回放的汇总说明，单题判分规则由新旧流程共用。

单题按全部适用得分点计算正确率；能力分项按适用题平均；场景分按场景内题目平均；综合主分对六个场景等权平均。六个能力维度没有额外权重。

当前规则来自 [scoring-policy.json](../../datasets/vision/astudio-v1/scoring-policy.json)，实现见 [score.mjs](../../scripts/astudio/vision/score.mjs) 和 [aggregate.mjs](../../scripts/astudio/vision/aggregate.mjs)。本文说明已有实现，不调整题目或判分标准。

## 1. 统计对象

一题对应一张固定图片及完整提示词，可以包含多个内容小问、批注和定位要求。评分对象是图像理解工具的首次原始回答；批注中的修改要求用于考察理解能力。

同一模型在当前题集的一轮评测中，每题计入一次。能力和场景是两个分类轴：一题只属于一个场景，可以同时考察多个能力。

### 六个场景

场景由 JSONL 的 `metadata.scene` 确定，`scene_name` 是展示名称，题量以题集 manifest 为准。

| 场景标识    | 场景名称         | 题数 | 题号                           | 新增文字、箭头批注 |
| ----------- | ---------------- | ---: | ------------------------------ | ------------------ |
| `canvas`    | 设计画布与图示   |   20 | `canvas-001`～`canvas-020`     | 有，共45条         |
| `webapp`    | 网页与应用截图   |   20 | `webapp-001`～`webapp-020`     | 有，共40条         |
| `photos`    | 日常照片         |   15 | `photo-001`～`photo-015`       | 无                 |
| `posters`   | 海报、插画与漫画 |   15 | `poster-001`～`poster-015`     | 无                 |
| `charts`    | 统计图表         |   15 | `chart-001`～`chart-015`       | 无                 |
| `documents` | 文档与票据       |   15 | `document-001`～`document-015` | 无                 |

后四类图片中的原有文字属于图片内容，不属于新增批注。

### 六个能力维度

| 能力维度               | 检查内容                           | 当前适用题数 | 原子得分点数 |
| ---------------------- | ---------------------------------- | -----------: | -----------: |
| 文字识别               | 图片中的文字、数字、符号           |           79 |          130 |
| 对象属性与状态识别     | 对象、颜色、数量、样式、选中状态等 |          100 |          250 |
| 空间布局与连接关系识别 | 位置、对齐、遮挡、连接和流程关系   |          100 |          126 |
| 批注目标识别           | 批注箭头指向的对象                 |           40 |           85 |
| 批注意图理解           | 修改动作、参数、保留项和共享约束   |           40 |          305 |
| 精确坐标定位           | 返回坐标与目标几何规则是否匹配     |          100 |          145 |

100题共1041个得分点，其中896个语义点、145个定位点。题数、点数均以 Gold 中的实际要求统计，不随模型回答的长短变化。

## 2. 评分点与能力维度的映射

能力归属读取 Gold 中明确标注的 `dimension`，不根据 ID 名称、关键词或 `tags` 推测。评分点与所在场景的关系，通过其所属题目的 `metadata.scene` 建立。

| 得分点来源             | 评分点 ID / 判定要求                                               | 能力归属                     |
| ---------------------- | ------------------------------------------------------------------ | ---------------------------- |
| 有批注题的内容小问     | `content_questions[].checkpoints[]` 中的 `id` / `expected`         | 继承所属小问的 `dimension`   |
| 无批注题的语义小问     | `content_questions[].checks[]` 中的 `id` / `text`                  | 继承所属小问的 `dimension`   |
| 批注的目标、意图评分组 | `annotations[].rubric[].checkpoint_ids[i]` / 同组 `checkpoints[i]` | 继承所属评分组的 `dimension` |
| 无批注题的定位目标     | `geometry` 中各问题 ID 对应的几何要求                              | 精确坐标定位                 |
| 有批注题的定位目标     | 每条 `annotations[].geometry`                                      | 精确坐标定位                 |

当前批注 `rubric` 按“目标识别、意图理解、坐标定位”排列。实现读取前两组生成语义点，第三组对应的定位要求由几何计算判分。`checkpoint_ids` 和 `checkpoints` 按数组下标一一对应。

例如批注 A 的意图评分组：

```json
{
  "dimension": "批注意图理解",
  "checkpoints": ["将填充改为浅蓝色", "保留：黑色边框"],
  "checkpoint_ids": ["A.change-1", "A.preserve-1"]
}
```

这生成两个“批注意图理解”得分点，每点满分1。改色要求与保留要求分别判定。

相关汇总字段的用途如下：

- 有批注题的适用性读取 `dimension_rubric[].applicable`；无批注题读取对应场景 manifest 中该题的 `applicable_dimensions`。JSONL 的 `metadata.applicable_dimensions` 保存同一题级分类，校验时核对一致性。
- `dimension_rubric`、`capabilities`、`tags`、`reference_answer` 本身不增加得分点。
- Gold 中的 `nominal_weight`、`points`、`points_per_checkpoint` 和原 contract 权重作为历史记录保留，当前不参与总分计算。
- 不适用维度应没有得分点；适用性标记与实际点数冲突时校验报错。

## 3. 逐点评分与单题总分

### 3.1 计分单位与判定

每个独立语义点、每个定位目标各计1点，正确为1，错误为0，不设半分。一个小问可以有多个独立点；定位的 x、y 合并判定一个定位点。

语义点按 Gold 要求逐项判断，接受满足要求的等价表述。当前回放沿用与原始答案和 Gold 哈希匹配的历史逐项判断；新答案需要对应的新语义判分记录，当前入口未启用在线裁判。

坐标先从0～1000归一化值换算为最终输入像素，再根据 Gold 判定：

```text
x像素 = x归一化 × 图片宽度 / 1000
y像素 = y归一化 × 图片高度 / 1000
```

| 定位类型                 | 得1点的条件                                                           |
| ------------------------ | --------------------------------------------------------------------- |
| 批注指向面状对象         | 返回点位于目标 bbox 内，包含边界                                      |
| 批注指向连线             | 返回点到目标折线的最短距离不超过 Gold 的 `max_distance_px`            |
| 无批注题的可见外接框中心 | 返回点与 Gold 中心的欧氏距离不超过 `tolerance_input_px`，本批为20像素 |

坐标缺失、越界、非有限数值，或同一标准目标对应多个重复答案时，该定位点得0。每个定位目标只计一次，不再将其文字检查项重复加入分母。

共享评分点只在 `shared_constraints` 声明的归属批注处计一次，其他批注引用该点。相同 ID 的原子点不能重复定义；目标、意图、定位分别判分，不因另一类失分而自动归零。

### 3.2 单题计算公式

对题目 i 和能力维度 d，定义：

- `N(i,d)`：该题该维度的标准得分点数。
- `E(i,d)`：这些点中答对的点数。
- `N(i)`：所有适用维度的 `N(i,d)` 之和。
- `E(i)`：所有适用维度的 `E(i,d)` 之和。

```text
单题基础分 B(i) = 100 × E(i) / N(i)
额外修改扣分 P(i) = 10 × 经语义判定的额外修改条数
单题最终分 S(i) = max(0, B(i) − P(i))
```

`content_questions` 和 `annotations` 的独立点合并进入 `N(i)` 与 `E(i)`。无批注题不适用额外修改扣分。扣分作用于单题最终分，不分摊到能力分项。

不适用维度记为 N/A，不进入分子、分母。调用超时等技术失败保留标准分母，全部适用维度得0分，仍计入场景和能力统计。结构合法性、schema、ID完整性另外记录诊断，不单独加分。

### 3.3 实例：canvas-001

| 来源                                       | 能力维度               |   点数 |
| ------------------------------------------ | ---------------------- | -----: |
| 内容小问：填充色、边框色、选中状态         | 对象属性与状态识别     |      3 |
| 内容小问：上下关系、水平中心对齐           | 空间布局与连接关系识别 |      2 |
| 批注 A：目标对象                           | 批注目标识别           |      1 |
| 批注 A：改色、保留边框、保留大小、保留位置 | 批注意图理解           |      4 |
| 批注 A：目标位置                           | 精确坐标定位           |      1 |
| **合计**                                   |                        | **11** |

如果仅定位点错误，其余10点正确，没有额外修改：单题分为 `100 × 10/11 ≈ 90.9091`。文字识别为 N/A，定位维度为0%，其余四个适用维度均为100%。批注 A 不完整正确，该题也不算整题完整正确。

## 4. 能力维度得分统计

先计算每题的维度得分率，再对该维度的适用题等权平均。

```text
单题能力得分率 R(i,d) = E(i,d) / N(i,d)       仅在 N(i,d) > 0 时定义
适用题集合 I(d) = 所有 N(i,d) > 0 的题
能力维度分 D(d) = 100 × Σ[R(i,d), i∈I(d)] / |I(d)|
```

若没有适用题，维度结果为 N/A。技术失败的适用题按0计入，不从集合中剔除。各维度分别平均，不再按六场景等权平均一次。

例如某个维度有以下三个统计项，数据仅用于说明计算：

| 题目 | 答对点数 / 标准点数 | 单题能力得分率 | 是否进入平均 |
| ---- | ------------------- | -------------: | ------------ |
| A    | 1/1                 |           100% | 是           |
| B    | 1/9                 |       11.1111% | 是           |
| C    | 0/0                 |            N/A | 否           |

最终能力维度分按未舍入值计算，为 `100 × (1 + 1/9) / 2 ≈ 55.5556%`。把两题的点数直接合并会得到 `2/10 = 20%`，这不是当前能力分项的统计口径。

能力汇总同时保存答对点数 `earned`、标准点数 `possible`、适用题数 `applicable_task_count`。这些计数用于追溯；展示的 `rate` 使用上述逐题得分率平均，不能用 `earned/possible` 覆盖。

## 5. 场景得分与综合主分

对场景 s，设其题目集合为 `T(s)`：

```text
场景分 C(s) = Σ[S(i), i∈T(s)] / |T(s)|
综合主分 = [C(canvas) + C(webapp) + C(photos) + C(posters) + C(charts) + C(documents)] / 6
```

场景内每题等权，已包含该题的额外修改扣分。六场景各占综合主分的1/6；20题场景和15题场景对综合主分的贡献相同。当前汇总要求六场景题量完整，缺题或重复题号报错，不能悄悄缩小分母。

例如六场景分依次为90、84、78、96、88、80，综合主分为 `516/6 = 86`。这些数值仅用于演示，不代表本次模型结果。

辅助统计与主分分开命名：

| 指标                                          | 统计方式              | 当前用途                                  |
| --------------------------------------------- | --------------------- | ----------------------------------------- |
| 综合主分 `score`                              | 六个场景分等权平均    | 主要对比分数                              |
| 跨题均分 `task_mean_score`                    | 全部100题最终分的平均 | 辅助指标；Promptfoo默认跨题均分对应此口径 |
| 答对/标准点数 `earned_points`、`total_points` | 累加各题独立得分点    | 追溯点数，不替代综合主分                  |

全部1041点直接合并求正确率、六个能力维度分再平均，都不是当前综合主分的计算方法。

## 6. 完整正确率与统计边界

### 整题完整正确率

一题全部适用点正确，且额外修改扣分为0，才算整题完整正确：

```text
整题完整正确率 = 整题完整正确的题数 / 本轮全部题数 × 100%
```

全量评测的分母为100，场景内统计使用该场景题数。调用失败的题算未完整正确。

### 批注完整正确率

一条批注的目标识别正确、全部意图点正确且定位正确，才算完整正确。全部意图包括该批注引用的共享要求；共享点答错会影响所有相关批注的完整性，但原子得分点仍只扣一次。

```text
批注完整正确率 = 完整正确的标准批注数 / 全部标准批注数 × 100%
```

全量汇总的分母为85，画布场景为45，网页应用场景为40。该指标按批注条数合并统计，不是先求每题批注正确率再平均。后四场景没有标准批注，此指标为 N/A。额外修改扣分不直接改变标准批注的完整性，但影响单题最终分和整题完整正确。

两项完整正确率均独立展示，不额外加入单题得分点，也不与综合主分加权合成。

## 7. 数据字段与单位

| 输出位置                                           | 含义与单位                                                                |
| -------------------------------------------------- | ------------------------------------------------------------------------- |
| 单题 `dimensions[d].earned` / `possible`           | 该能力答对点数 / 标准点数                                                 |
| 单题 `dimensions[d].rate`                          | 单题该能力得分率，0～1；不适用为 `null`                                   |
| 单题 `earned_points` / `total_points`              | 全部能力合计的答对点数 / 标准点数                                         |
| 单题 `base_score` / `extra_edit_penalty` / `score` | 基础分 / 扣分 / 最终分，百分制                                            |
| 单题 `annotation_complete_rate_percent`            | 该题批注完整正确率，0～100；无批注为 `null`                               |
| 汇总 `dimensions[d].rate`                          | 适用题该能力得分率的平均，0～1                                            |
| 汇总 `scenes[].score` / `score`                    | 场景分 / 六场景综合主分，百分制                                           |
| 汇总 `annotation_complete_rate`                    | 合并统计的批注完整正确率，0～1；无批注为 `null`                           |
| Promptfoo 单条结果 `score` / `namedScores`         | 单题最终分除以100 / 各适用能力得分率，0～1；具名分项另含“整题完整正确”0/1 |

公式使用未四舍五入值计算。界面显示时再转为百分比或保留小数，不能先舍入单题分再汇总。
